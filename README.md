# Swiggy Analysis — Power BI Dashboard

## Overview

This project is a Power BI dashboard created to analyze Swiggy's sales and order performance across different time periods, food types, restaurants, and states.

The dashboard focuses on understanding overall sales performance, order volume, customer ratings, restaurant contribution, and geographic sales distribution.

## Business Questions

* How much total sales and how many orders were generated?
* What is the average order value and average customer rating?
* How do sales change over time?
* How are orders distributed between vegetarian and non-vegetarian food?
* Which restaurants contribute the most to sales?
* Which states generate the highest sales?
* How does sales performance vary across different days and periods?

## Dashboard Analysis

### Key Metrics

* Total Sales: ₹53.01M
* Total Orders: 197K
* Average Order Value: ₹268.51
* Average Rating: 4.34
* Rating Count: 5.59M

### Sales & Order Trends

The dashboard analyzes monthly, daily, and weekly trends to understand how sales and order activity change over time.

### Food Type Analysis

Orders are analyzed by food type to compare vegetarian and non-vegetarian order volumes.

### Restaurant Analysis

The dashboard highlights the top restaurants by sales, including KFC, McDonald's, Pizza Hut, Burger King, and Domino's Pizza.

### Geographic Analysis

Sales are analyzed across states to identify the major geographic contributors to overall sales.
